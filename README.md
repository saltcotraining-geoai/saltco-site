# saltco — Open-Source Computing & Capacity Building

Static educational site for geospatial AI training. Fully offline-capable, no external dependencies, MIT licensed.

## Pages

- Home, Learning Paths, Courses, Blog, Projects, Downloads, Book, About

## Deploy (GitHub Pages)

Push this repo, then in Settings → Pages, select **Deploy from a branch** and choose `main` / root. Add your custom domain under Settings → Pages → Custom domain.
