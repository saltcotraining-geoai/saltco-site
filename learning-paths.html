Learning Paths

Track 1: Digital Literacy Foundations

Core computing confidence and an open-source mindset. File systems, offline productivity (LibreOffice), data formats, digital security.

Track 2: Open-Source Geospatial Basics

Real-world mapping with QGIS. Vector/raster visualization, styling, KoboToolbox for offline field collection, OpenStreetMap mapathons.

Track 3: Advanced Spatial Analytics & Programming

From maps to data science. Buffers, terrain models, remote sensing (NDVI), PyQGIS automation, and global processing engines.

Track 4: Community Leadership & Professional Practice

Connect skills to employment. GitHub portfolios, a capstone project tackling real local challenges, and a train-the-trainer evaluation.

Track 5: Geospatial AI & Agents

The frontier. Local LLMs with Ollama, RAG knowledge bases, spatial agents, and multi-agent systems — all running offline.
